Artifacts

Reusable startup state the scheduler plans from. Weights are keyed by model and revision. Compile caches are keyed by SGLang version, GPU, TP and model config, so any workload with the same key reuses one (2×H100 and 4×H100 groups share the TP=2 cache). A copy is validated once an engine has served traffic with it.

Volumes

Each model has its own Modal volumes, so loading one model never competes with another's reads. A model the catalog hasn't seen gets new volumes on its first start (weights on the prep worker, compile cache on write-back).

Engine registry

Engines the control plane is tracking. Engines in the same sandbox (GPU groups) share its lifetime. The reconciler checks every 30 s that each one is still running.

Learned timings

The scheduler's estimates. Each model learns its own from its launches (exponential moving average, weight 0.5); until it has a value it borrows the shared one, which starts from the vanilla-baseline prior. Starts with several engines per host don't feed these.
